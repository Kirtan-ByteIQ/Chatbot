An AI-powered local chatbot that can process documents and images and answer questions using Retrieval-Augmented Generation (RAG).

## 🚀 Features

- 📄 PDF/document processing
- 🖼️ Image processing and OCR
- 🔍 Semantic search using vector embeddings
- 🧠 Retrieval-Augmented Generation (RAG)
- 💬 Question answering over uploaded documents
- 🏠 Runs locally without requiring external AI API keys
- 🗄️ Vector database for storing document embeddings

## 🛠️ Tech Stack

- Python
- Sentence Transformers
- ChromaDB
- OCR
- Local LLM
- RAG
- Embeddings
